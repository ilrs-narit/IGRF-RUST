# แยก OS แบบอ่านอย่างเดียวออกจากข้อมูลถาวร

เครื่องต้นแบบ Buildroot ใช้ OS แบบอ่านอย่างเดียว และพื้นที่เขียนแยกสำหรับค่าตั้งเครื่อง ฐานข้อมูล CSV logs และเครือข่ายที่จำไว้ เพื่อให้ฐานระบบที่ตรึงเวอร์ชันแยกจากข้อมูลระหว่างใช้งาน แทนการเปิดให้เขียนได้ทั้งระบบ การเลือกนี้ต้องจัดตำแหน่งข้อมูลเขียนของบริการต่าง ๆ และเปลี่ยน OS ผ่านการสร้าง image ใหม่ แทนการแก้ไฟล์ระบบถาวรผ่าน SSH

การแยกพื้นที่ไม่ได้รับประกันความปลอดภัยของข้อมูลเมื่อไฟดับ และไม่ได้รักษาข้อมูลเมื่อเขียน image ทับทั้ง microSD; ต้องมีการตรวจข้อมูลเสีย สำรอง และทดสอบการกู้คืนตามข้อกำหนดใน [ร่างออกแบบ](../buildroot-design.md)
