# ใช้ Buildroot พร้อมชุดหน้าจอเดิมสำหรับเครื่องต้นแบบ

ผู้ใช้ยืนยันให้สร้างระบบ Pi 5 ด้วย Buildroot แบบ BR2_EXTERNAL ใช้ systemd ดูแลบริการ และคง X11 กับ Onboard เพื่อลดการเปลี่ยนพฤติกรรมหน้าจอเดิม แทนการย้ายระบบแสดงผลในรุ่นแรก โดยยอมรับภาระจัดแพ็กเกจและ dependencies ของชุดเดสก์ท็อปบน Buildroot

ระบบใช้ NetworkManager สำหรับ LAN/Wi-Fi และ OS อ่านอย่างเดียวกับข้อมูลถาวรแยกตาม ADR 0001 อัปเดตต้นแบบด้วยการสำรองข้อมูล เขียน microSD ใหม่ และนำข้อมูลกลับ; ยังไม่เลือก release หรือรับรอง cross-build จนผ่านจุดตรวจใน [แบบระบบ](../buildroot-design.md)
